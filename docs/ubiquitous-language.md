## 1. 目的

本ドキュメントは、トレーディングカード買取システムにおけるドメイン用語を統一し、顧客・開発者間の認識齟齬を防ぐことを目的とする。

---

## 2. コアドメイン用語

### 2.1 買取関連

| 用語 | 定義 |
|------|------|
| **買取票** | 商品一覧と買取価格を表示するWebページ。顧客が売却したい商品を選択し、見積金額を確認するための画面。 |
| **買取同意書** | 顧客が売却意思を表明するフォーム。個人情報・売りたい商品・数量を入力し、法的同意を得る。 |
| **買取価格** | 商品1点あたりの買取金額。商品ごとに設定され、買取票および買取同意書で表示される。 |
| **査定** | 商品の状態・価値を評価する行為。到着後の検品に基づき、最終買取金額を決定する。 |

### 2.2 商品・カテゴリ

| 用語 | 定義 |
|------|------|
| **商品** | 買取対象のトレーディングカード商品。商品ID・商品名・買取価格・画像を持つ。 |
| **カテゴリ** | 商品の分類。例：ポケモン未開封、ワンピース未開封、AR最低保証。 |
| **商品ID** | 各商品に一意に付与される識別子。AmazonのASINに相当する概念。 |

### 2.3 顧客・取引

| 用語 | 定義 |
|------|------|
| **顧客** | 商品を売却する個人。買取票を閲覧し、買取同意書を提出する。 |
| **見積金額** | 買取票で選択した商品・数量に基づく合計金額。査定前の暫定値。 |
| **最終買取金額** | 査定後に確定した買取金額。顧客への入金額となる。 |

### 2.4 将来フェーズで追加予定の用語

| 用語 | 定義 |
|------|------|
| **古物台帳** | 古物営業法に基づく取引記録。警察照会に対応するため保管が義務。 |
| **受入** | 古物台帳の区分。買取（商品を仕入れた取引）を指す。 |
| **払出** | 古物台帳の区分。販売（商品を売った取引）を指す。 |

## 3. エンティティ一覧

| エンティティ | 説明 |
|-------------|------|
| 顧客 | 買取同意書を提出する個人 |
| 商品 | 買取対象のトレーディングカード商品 |
| カテゴリ | 商品の分類 |
| 買取同意書 | 顧客の売却申込データ（個人情報・商品選択・数量を含む） |

---

## 4. ステータス定義

買取同意書・取引のライフサイクルを表すステータス。

| ステータス | 説明 |
|-----------|------|
| **受付済** | 買取同意書が提出され、システムに記録された状態 |
| **査定中** | 商品の検品・査定を実施中の状態 |
| **買取完了** | 最終金額が確定し、入金が完了した状態 |
| **キャンセル** | 取引が中止された状態 |

## 6. 固有名詞の扱い

顧客・同僚向けドキュメントでは、実名を使用せず以下の役割名または架空の外国人名を用いる。

| 役割 | 架空名 | 説明 |
|------|--------|------|
| プロジェクトオーナー（発注者） | Alex Smith | 事業代表 |
| 開発者 | James Chen | システム開発担当 |
| デザイナー | Sarah Wilson | ロゴ・デザイン素材作成担当 |
